# Fixed-seed cyclic rank as reduced inverse-root span

## Assessment

Yes. This is the right successor problem, and it should be framed as an **algebraic classification of reduced inverse-root spans**, with the cyclic-rank statement demoted to a corollary conditional on the stationary-phase bridge.

One wording needs tightening. The example does **not** violate right-factor heredity,

[
\dim W_Q^{\mathrm{red}}\le \dim W_P^{\mathrm{red}}.
]

It saturates it:

[
\dim W_{x^4+x}=3=\dim W_{(x^4+x)^3}.
]

What fails is the naive **additive block rule** under which three quartic blocks would contribute roughly (3\times3=9) directions. The release itself makes this distinction: the block dimensions need not add because symmetry can make their spans coincide. ([Evidence Press][1])

## Why ((x^4+x)^3) is the correct generating example

Set

[
Q(x)=x^4+x,\qquad P(x)=Q(x)^3.
]

The identity

[
Q(\zeta x)=\zeta Q(x),\qquad \zeta^3=1,
]

makes the three blocks over (Q(x)=y,\zeta y,\zeta^2y) scalar copies of one another. Each block has dimension three, but all three occupy the same three-dimensional space.

The same polynomial has the Ritt-moved decomposition

[
P(x)=H(x^3),\qquad H(y)=y(y+1)^3.
]

Thus one decomposition presents the rank defect as **three coincident three-dimensional block spans**, while the other presents it as **four root lines spanning only three dimensions**. That dual presentation is exactly why the example should generate the theory. A classification tied to one preferred decomposition will miss the invariant structure.

It is the smallest nontrivial instance of Ritt’s monomial collision

[
x^n\circ \bigl(x^rS(x^n)\bigr)
==============================

\bigl(x^rS(x)^n\bigr)\circ x^n,
\qquad \gcd(r,n)=1,
]

with (n=3), (r=1) and (S(x)=x+1). Ritt theory says that, up to linear changes, nontrivial elementary polynomial collisions have this monomial form or the Chebyshev form

[
T_n\circ T_m=T_m\circ T_n.
]

It also says that complete decompositions of one polynomial are connected by sequences of such elementary moves. ([arXiv][2])

The critical values display the same fusion. Since

[
P'(x)=3Q(x)^2Q'(x),
]

the roots of (Q) give the critical value (0). At a root (c) of (Q'(x)=4x^3+1),

[
c^3=-\frac14,\qquad Q(c)=\frac{3c}{4},
]

and hence

[
P(c)=Q(c)^3=-\frac{27}{256}.
]

The three distinct critical values of the quartic (Q) therefore become one value after cubing. Thus (P) has only the two finite branch values

[
0,\qquad -\frac{27}{256}.
]

Root-block fusion, critical-value fusion and the Ritt collision are three descriptions of the same structure.

## The exact standalone theorem

Define the algebraic invariant

[
\rho(P):=\dim_{\mathbf C}W_P^{\mathrm{red}}.
]

The successor paper should prove a theorem of the following form.

> **Decomposable low-root-span classification.**
> Classify, up to invertible affine changes of source and target, every polynomial (P\in\mathbf C[x]) satisfying
> [
> \rho(P)\le3.
> ]
> For every class, give all complete decompositions, its Ritt graph, the block-fusion profile attached to every right factor, all intersections between the normal-form families, and an exact recognition procedure.

The fixed-seed result would then appear only as:

> Conditional on the stationary-phase bridge,
> [
> q(P,dx)=\rho(P),
> ]
> so the same atlas classifies fixed-seed cyclic rank at most three.

This separation matters. The release remains an unrefereed candidate whose analytic bridge has not received independent or external specialist verification. An algebraic inverse-root classification would retain its principal theorem even if that bridge later required revision. ([Evidence Press][1])

## A sharper invariant: infinity-character support

The block-fusion problem admits a useful exact reduction that should come before the case analysis.

Let (d=\deg P), let (\tau) be the full (d)-cycle at infinity, and let (\zeta=\exp(2\pi i/d)). Because the restriction of the augmentation module to (\langle\tau\rangle) is multiplicity-free, there is a subset

[
A(P)\subset \mathbf Z/d\mathbf Z\setminus{0}
]

such that

[
W_P^{\mathrm{red}}
==================

\bigoplus_{a\in A(P)}\mathbf C u_a,
\qquad
\tau u_a=\zeta^a u_a.
]

Consequently,

[
\rho(P)=|A(P)|.
]

Now suppose (P=R\circ Q), with (\deg Q=m) and (d=mn). Label the inverse roots so that the (b)-th (Q)-block consists of indices

[
b,\ b+n,\ b+2n,\ldots,b+(m-1)n.
]

Fourier inversion gives

[
x_{b+kn}
========

\sum_{a\in A(P)}
\zeta^{ab}\zeta_m^{ak}u_a.
]

As (k) varies, the block span is generated by

[
v_{r,b}
=======

\sum_{\substack{a\in A(P)\a\equiv r\pmod m}}
\zeta^{ab}u_a.
]

Therefore

[
\boxed{\rho(Q)=\bigl|A(P)\bmod m\bigr|.}
]

This formula converts block fusion into a partition of a set of at most three characters by congruence modulo the degree of the right factor. Ritt moves change the relevant modulus and hence change the visible partition, while the global support (A(P)) remains the same.

For the natural infinity generator of

[
P=(x^4+x)^3,
]

one obtains

[
A(P)={1,7,10}\subset\mathbf Z/12\mathbf Z.
]

The two decompositions now become transparent:

[
A(P)\bmod4={1,3,2}.
]

All three characters remain separate, so the quartic block has dimension three. Since the global space also has dimension three, every quartic block equals the whole space.

By contrast,

[
A(P)\bmod3={1}.
]

All three characters collapse into one residue class, so each (x^3)-block is a line. The four lines arising from the four roots of (H(y)-z) span the same three-dimensional global space. The Ritt move therefore exchanges:

[
\text{three coincident (3)-spaces}
\quad\longleftrightarrow\quad
\text{four dependent lines}.
]

This character-support lemma would give the paper a clean internal spine. It also makes “equivariant fusion” computationally testable rather than metaphorical.

## The low-rank case split

For (P=R\circ Q) and (\rho(P)\le3), only three block geometries can occur.

| (\rho(Q)) | Blocks inside (W_P)                          | Required phenomenon                                                              |
| --------: | -------------------------------------------- | -------------------------------------------------------------------------------- |
|         1 | Lines in a space of dimension at most three  | At most three independent lines; higher outer degree requires exact dependencies |
|         2 | Planes in a space of dimension at most three | Complete coincidence or a tightly constrained common-line configuration          |
|         3 | Three-dimensional spaces                     | Every block must equal (W_P): complete fusion                                    |

The third row is especially rigid. It should yield the first substantial classification theorem.

### Quartic fusion rigidity

A precise target is:

> Let (Q) be an indecomposable quartic and (R) nonlinear. If
> [
> \rho(R\circ Q)=3,
> ]
> then, up to affine source and target changes,
> [
> Q=x^4+x,\qquad R=x^3.
> ]

There is a plausible short route.

An indecomposable quartic has (S_4) monodromy on its three-dimensional standard module. Complete fusion makes the full monodromy of (R\circ Q) act on that same module and normalize the inner (S_4). Since the standard representation is irreducible and every automorphism of (S_4) is inner,

[
N_{\mathrm{GL}_3}(S_4)=\mathbf C^\times S_4.
]

After composing with an inner permutation, transport between blocks must therefore act by a scalar. At the polynomial level this forces a semiequivariance identity

[
Q(\lambda x)=\alpha Q(x)+\beta.
]

Coefficient comparison for a depressed indecomposable quartic leaves only the order-three possibility

[
Q(x)\sim x^4+ax,\qquad a\ne0,
]

which scales to (x^4+x). Transitivity on the resulting three target values then forces (R) to be cyclic of degree three, hence affine-equivalent to (x^3).

Some extension and normalizer details still require proof, but this is much narrower than an unrestricted quartic calculation. It would explain why the released example is canonical rather than accidental.

## Proof architecture for the complete atlas

### 1. Bound the branch complexity

The candidate’s algebraic conductor equality gives

[
\sum_v\operatorname{rank}(\sigma_v-I\mid W_P)
=============================================

\dim W_P.
]

The action on (W_P) is faithful: an element fixing (W_P) fixes every inverse root and hence the entire splitting field. Every nontrivial finite inertia generator therefore contributes at least one. It follows that

[
\boxed{#{\text{finite branch values of }P}\le \rho(P)\le3.}
]

This sharply bounds the Hurwitz data before any decomposition analysis. It also passes the generating-example check: ((x^4+x)^3) has two finite branch values.

### 2. Classify rank transitions along decomposition chains

For a complete decomposition

[
P=P_1\circ P_2\circ\cdots\circ P_k,
]

record the ranks of successive suffixes. They form a nondecreasing sequence in

[
{1,2,3}.
]

There can be at most two strict increases. Long decompositions must therefore consist mainly of rank-preserving steps, and rank-preserving steps require complete block fusion. This turns an arbitrary-length decomposition problem into a finite-state transition problem:

[
1\to1,\quad1\to2,\quad1\to3,\quad
2\to2,\quad2\to3,\quad
3\to3.
]

### 3. Solve the two elementary Ritt moves locally

For the monomial collision, express the fusion criterion through the residue partitions of (A(P)). For the Chebyshev collision, use the two Joukowski characters and determine when the block transport preserves their two-dimensional span.

Each elementary move should receive an explicit transition rule:

[
(A,m)\longmapsto(A,m'),
]

where (m) and (m') are the degrees of the exchanged right factors.

### 4. Use normalizers for complete fusion

When (\rho(Q)=\rho(P)), every block span equals the global span. The full monodromy normalizes the image of the inner monodromy on this low-dimensional space. The relevant normalizer quotients in dimensions one, two and three should classify the possible outer actions.

This should close:

* powers in dimension one;
* Chebyshev and monomial groups in dimension two;
* the quartic (S_4) case above;
* any recursively generated decomposable rank-two or rank-three kernels.

### 5. Treat line fusion projectively

When the right factor has rank one, the blocks are points of

[
\mathbf P(W_P)\cong\mathbf P^0,\ \mathbf P^1,\ \text{or }\mathbf P^2.
]

The outer monodromy acts transitively on this point configuration. In dimension two, finite projective groups reduce to cyclic, dihedral and the bounded polyhedral cases. In dimension three, imprimitive monomial families account for the unbounded-degree possibilities; the primitive exceptional groups form a bounded list.

This gives a plausible completeness strategy:

* derive the unbounded parametric families from monomial and Chebyshev Ritt forms;
* enumerate the bounded exceptional projective actions;
* reject or retain each one using branch-cycle and polynomial-genus-zero constraints.

### 6. Build exact recognition into the theorem

The recognition algorithm should return more than (\rho(P)). For an input (P), it should produce:

1. an affine-normalized representative;
2. every complete decomposition;
3. the Ritt graph connecting them;
4. (A(P)) and its residue partition for every right-factor degree;
5. the block-intersection dimensions;
6. the matched normal-form family;
7. exact certificates for all identities and rank claims.

The existing Krylov reducer already supplies an independent global rank oracle. It can serve as a comparator while the new algorithm works from decomposition and character data. ([Evidence Press][1])

## The main logical danger

Ritt theory tells us how to pass between decompositions once multiple decompositions exist. It does **not**, by itself, prove that every unexpected linear relation among block spans creates another decomposition.

The completeness theorem therefore needs a statement resembling:

> For (\rho(P)\le3), every non-generic block fusion is caused either by:
>
> 1. an outer map of degree at most three;
> 2. a monomial or Chebyshev Ritt collision; or
> 3. one of a finite, explicitly classified exceptional projective-monodromy cases.

The third clause cannot simply be omitted. Work on zero-dimensional Abelian integrals provides examples of root relations that do not arise as sums of composition terms. That is not a counterexample to this particular inverse-root-span claim, but it warns against treating “linear relation” and “hidden decomposition” as synonyms without proof. ([arXiv][3])

## Priority judgement

The full decomposable (\rho\le3) classification is a better standalone target than another refinement of the conditional cyclicity theorem. It would contribute:

* an unconditional algebraic theorem about inverse roots;
* a new invariant description of fusion through infinity-character support;
* a bridge between root-relation modules and Ritt decomposition theory;
* an exact classification and recognition algorithm;
* and, conditionally, the arbitrary-degree fixed-seed cyclic-rank atlas that the current release deliberately withholds.

The immediate first milestone should be **quartic fusion rigidity generated by ((x^4+x)^3)**, accompanied by the character-support/block-residue lemma. Together they would determine whether the broader atlas is likely to collapse to Ritt-normal parametric families plus a finite exceptional ledger.

### Sanity checks

[
\deg\bigl((x^4+x)^3\bigr)=12=3\cdot4=4\cdot3.
]

[
\rho(x^4+x)=3=\rho((x^4+x)^3),
]

so heredity is satisfied exactly.

[
A(P)={1,7,10},\qquad
|A\bmod4|=3,\qquad
|A\bmod3|=1.
]

The two finite critical values are

[
0,\qquad-\frac{27}{256}.
]

All four checks point to the same mechanism: the polynomial is the minimal Ritt collision in which a rank-three quartic constituent survives composition because its symmetry fuses the outer blocks completely.
